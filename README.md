# CIAP---Sentiment-Analysis
## Instalación
1. Clonar el repo
2. pip install -r requirements.txt

## Abrir `notebooks/01_limpieza.ipynb`

Si el kernel de VS Code no conecta, ejecutar desde la raíz del repo:

    python -m jupyter lab

Se abre en el navegador; desde ahí se puede abrir y ejecutar el cuaderno.
